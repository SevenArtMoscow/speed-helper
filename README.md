# SPEED HELPER

Telegram Mini App для поиска краткосрочных смен и исполнителей. Техническое задание v1.0.

- Запуск локально: `python3 -m http.server 8765` → http://localhost:8765 (без Supabase работает в локальном режиме).
- Каждая вкладка браузера = отдельный пользователь (см. «Профиль → Режим разработки»); Telegram ID 1 = админ.
- Архитектура и статус: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
- `legacy/` — прежний прототип v5.8.
