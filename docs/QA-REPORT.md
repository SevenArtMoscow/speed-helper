# SPEED HELPER — QA-отчёт (полное тестирование перед запуском)

Дата: 7 октября 2026. Версия: ветка `main` + исправления из этого отчёта (миграция `008_qa_fixes.sql`).

## Как тестировали
- **Автотесты сервера**: `cd server && npm test` — настоящий сервер на встроенной PostgreSQL. Было 188 проверок, стало **217** (+29 на найденные дефекты). Все проходят.
- **Ручной прогон интерфейса** (мобильный размер 375×812, эмуляция Telegram WebApp с подписанными `initData`, настоящие сервер и база, включая защиту CSP): четыре «пользователя» одновременно — исполнитель, два подрядчика, администратор. Более 150 проверок по каждому экрану и кнопке.
- **Чтение кода** всех экранов и SQL-логики (поиск логических ошибок, которые не видны из интерфейса).

## Известные ограничения и риски (не дефекты кода — решения для владельца)
1. **Не проверялось на реальном телефоне в Telegram**: вибрация, клавиатура и перекрытие экрана, кнопка «Назад» Telegram, открытие внешних ссылок, определение местоположения («Рядом со мной»). Нужен закрытый тест на 2–3 телефонах (iOS и Android).
2. **Нагрузочное тестирование не проводилось.** Лимиты запросов и пул соединений настроены, но реальную нагрузку покажет пилот.
3. **Пересечение смен у исполнителя не проверяется**: человека можно принять на две смены в одно время. Нужно ли запретить — решение продукта.
4. **Смены не закрываются автоматически**: подрядчик сам нажимает «Смена завершена». Прошедшие смены скрыты из ленты, но остаются у подрядчика в «Активных».
5. Админ-панель показывает последних 500 пользователей и 300 смен без поиска — при росте базы понадобится поиск и страницы.
6. Вкладка в «Моих сменах» запоминается на время сеанса (после отклика можно попасть на ранее открытую вкладку «Отменённые») — мелкое неудобство.
7. Режим разработки (`js/local-backend.js`, `?local=1`) не получил этих исправлений; в боевой работе не используется.
8. Уведомления в Telegram от бота и рассылка проверены автотестом бота, но не «вживую».
9. Юридические тексты должны проверить юрист; в `server/.env` нужно заполнить `OPERATOR_NAME` и `OPERATOR_CONTACT`.

## Как выкатить исправления
```bash
speedhelper-backup && G="git -c safe.directory=/opt/speedhelper -C /opt/speedhelper"; $G fetch -q origin main && $G reset -q --hard origin/main && chown -R speedhelper:speedhelper /opt/speedhelper && (cd /opt/speedhelper/server && npm ci --omit=dev --silent) && systemctl restart speedhelper && sleep 4 && curl -s https://speedhelper.ru/api/health
```
Миграция 008 применится сама при запуске (только заменяет функции, данные не трогает).
